# 🧭 GTÜ-NAV: Yaya Odaklı Akıllı Kampüs Navigasyon ve Yaşam Platformu

Gebze Teknik Üniversitesi (GTÜ) yerleşkesinde öğrencilerin, akademisyenlerin ve ziyaretçilerin kampüs içi ulaşımını kolaylaştıran; **yoldan sapmayan yaya navigasyonu (`Snap-to-Path`)**, **anlık boş derslik/amfi radarı**, **yerel CPU yapay zekâ destekli yazılı kampüs bildirim (ticket) sistemi** ve **harita tabanlı canlı Admin Komuta Merkezi** sunan web/mobil uyumlu platform.

## 🚀 Hızlı Başlangıç (Docker)

```bash
docker compose up --build
```

- **Ön Yüz (Web / Mobil Arayüz):** `http://localhost:3000`
- **Arka Uç API & Dokümantasyon:** `http://localhost:8000/docs`
- **Sağlık Kontrolü:** `http://localhost:8000/health`
